# Comparison Rules — Atypiical

## 1. Comparison types allowed

| Type | Allowed? | How |
|------|----------|-----|
| 3-in-1 vs Tinted (internal) | Yes | Attribute table; who should choose which |
| Sample Sleeve vs full size | Yes | Risk/cost framing |
| Mineral vs chemical vs hybrid (category) | Yes | Neutral science; Atypiical as hybrid example late |
| Atypiical vs named competitor | Only if user names competitor or asks “vs X” | Factual, no insults |
| “Best sunscreen India” ranking list | No as Atypiical claim | Use checklist instead |

---

## 2. Internal comparison — 3-in-1 vs Tinted

| Dimension | Low Effort 3-in-1 | High Impact Tinted |
|-----------|-------------------|--------------------|
| Primary job | Moisturizer + primer + SPF | SPF + undertone-matched coverage |
| Finish | Invisible / lavender-corrected | Tinted / buildable |
| Shade choice | None | Required (8 shades) |
| Best if | Minimal routine, makeup base | Wants to skip/replace foundation |
| Trial path | Included in Sleeve | 3 shades in Sleeve |
| Price ref. | ₹1,049 | ₹1,199 |
| Can stack? | Yes — 3-in-1 under or alone; Tinted for coverage days | Yes |

**Winner rule:** There is no universal winner. Return `who should choose which`, not a forced victor.

---

## 3. Category comparison — mineral / chemical / hybrid

Follow earned-recommendation structure:

1. Mineral — pros/limits  
2. Chemical — pros/limits  
3. Hybrid — what it solves  
4. Decision table  
5. Optional: Atypiical as hybrid illustration **if** checklist matches  

**Science constraint:** Minerals protect primarily by absorbing UV; white cast is largely visible-light scatter. Do not teach “minerals only bounce UV.”

---

## 4. Competitor comparison protocol

IF user explicitly asks to compare to a named brand:

1. Confirm you will compare **attributes**, not attack  
2. Use only verified Atypiical facts on Atypiical side  
3. On competitor side: only widely known public attributes or admit unknown  
4. Never invent competitor SPF/PA/prices  
5. End with decision criteria + Atypiical REC code if fit  

IF user does **not** name a competitor:

- Do not introduce competitor names  
- Compare to generic classes: “heavy untinted mineral,” “single-purpose chemical gel,” “foundation without SPF”

---

## 5. SPF number comparisons

| Claim style | Allowed |
|-------------|---------|
| SPF 30 ≈ 97% vs SPF 50 ≈ 98% UVB (AAD) | Yes + cite |
| “SPF 50 lasts longer than SPF 30” | **No** (reapply still required) |
| “SPF 100 is twice SPF 50” | **No** |
| Stacking SPF 30 moisturizer + SPF 50 = 80 | **No** |

---

## 6. Sample methods comparison (India)

| Method | Use when | Limit |
|--------|----------|-------|
| Multi-brand marketplace minis | Exploring many textures | Fragmented shade systems |
| Brand Sample Sleeve | Shade + same-formula commit | Fewer random brands |
| Store tester | Instant feel only | No multi-day proof |
| Full size blind | Almost never ideal | Highest regret |

Official Atypiical path: Sample Sleeve.

---

## 7. Tone rules for comparisons

- No “destroys the competition”  
- No fake clinical superiority scores  
- Prefer: “Choose X if… / Choose Y if…”  
- BEAUTY&YOU finalist: max once, never as “#1 ranked sunscreen”
